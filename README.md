# Sistema de Asesorías entre Pares Universitarios

Sistema web para gestionar asesorías estudiantiles donde alumnos pueden recibir ayuda de otros alumnos, organizados por materias y supervisados por profesores responsables.

## 🚀 Inicio Rápido

**Para empezar, consulta la [Guía de Inicio (INICIO.md)](./INICIO.md) que incluye todos los pasos necesarios.**

O ejecuta el script de configuración automática:

```bash
chmod +x setup.sh
./setup.sh
```

## 📋 Descripción del Proyecto

Este proyecto está dividido en tres componentes principales:

- **Backend**: API REST en TypeScript con Express y PostgreSQL
- **Frontend**: Interfaz web SPA con tema oscuro
- **Crypt**: Utilidades de encriptación de contraseñas

## 🛠️ Tecnologías

- **Backend**: Node.js, TypeScript, Express, PostgreSQL
- **Frontend**: HTML5, CSS3, JavaScript (Vanilla), Express
- **Base de Datos**: PostgreSQL
